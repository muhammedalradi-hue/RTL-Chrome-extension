# RTL Toggle

<div dir="rtl">

إضافة Chrome تصلح اتجاه ومحاذاة النصوص العربية في الصفحات التي تعرضها من اليسار
إلى اليمين، بنقرة واحدة ودون تحديث الصفحة.

الإضافة **مفتوحة المصدر** — الشيفرة كاملة هنا للاطلاع والمراجعة.

## المزايا

- **تشغيل وإيقاف فوريان** من أيقونة الإضافة، وحالة مستقلة لكل تبويب.
- **تثبيت المواقع الدائمة:** اضغط بزر الفأرة الأيمن على أيقونة الإضافة واختر
  «تشغيل دائمًا على هذا الموقع» — يعمل الإصلاح تلقائيًا مع كل فتح لصفحات هذا
  الموقع. الإضافة تطلب إذن الوصول لهذا الموقع وحده عند التثبيت.
- **صفحة إدارة** لعرض المواقع المثبّتة وإزالتها؛ الإزالة تسحب إذن الموقع أيضًا.
- **لا يعمل على أي موقع إلا بطلبك** — لا صلاحيات وصول واسعة عند التثبيت.
- **لا يجمع أي بيانات ولا يرسل شيئًا لأي جهة خارجية؛** كل المعالجة داخل المتصفح.

## التثبيت

من متجر Chrome الإلكتروني، أو يدويًا للتجربة:

1. نزّل المستودع أو فك ضغط حزمة الإصدار.
2. افتح `chrome://extensions` وفعّل **وضع المطوّر**.
3. اضغط **تحميل غير مضغوط** واختر مجلد الإضافة (الذي فيه `manifest.json`).

## الخصوصية

- ما يُخزَّن: **قائمة المواقع التي ثبّتها المستخدم بنفسه فقط**، في
  `chrome.storage.local` داخل المتصفح.
- ما لا يُجمع: لا سجل تصفح، ولا محتوى صفحات، ولا أي بيانات شخصية.
- لا اتصال بأي خادم خارجي، ولا شيفرة تُحمَّل عن بُعد.

## بنية المشروع

| الملف | الدور |
| --- | --- |
| `manifest.json` | تعريف الإضافة وصلاحياتها (Manifest V3) |
| `background.js` | عامل الخدمة: الأيقونة، قائمة الزر الأيمن، المواقع الدائمة وتسجيل سكربت المحتوى |
| `content.js` | منطق كشف النص العربي وضبط اتجاه أقرب حاوية مناسبة |
| `content.css` | أنماط RTL، مع إبقاء الأكواد وكتل `pre` بالاتجاه اللاتيني |
| `options.html/.css/.js` | صفحة إدارة المواقع الدائمة |

## الترخيص

انظر ملف الترخيص في المستودع إن وُجد؛ وإلا فجميع الحقوق محفوظة لصاحب المستودع.
